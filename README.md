# enmipccorre.dev

Mi página principal: quién soy, cómo contactarme y qué he construido.

HTML y CSS a mano, sin frameworks ni dependencias. Se publica con GitHub
Pages desde la rama `main`; el archivo `CNAME` le dice a GitHub que
responda en `enmipccorre.dev`.

Para agregar un proyecto: copiar el `<article class="proyecto">` de
`index.html`, cambiar el texto y dejar la captura en `img/`.
